## Formato

- **PNG preferido** (JPG también sirve).
- `logo-primary` idealmente **1024×1024** y cuadrado.
- `logo-mono` mejor con **fondo transparente** (si tu herramienta lo permite).
- Si tu archivo tiene otro nombre, no pasa nada — lo detecto igual. Solo avísame.

## Qué haré con ellas

1. Reviso cuál se lee mejor a tamaño pequeño (16–32px).
2. Genero el **`.ico` multi-resolución** (16/32/48/64/128/256) → `assets/icons/icon.ico`.
3. Configuro el icono del **instalador NSIS** y del desinstalador.
4. (Opcional) uso `logo-lockup` en el sidebar/splash y guardo las otras como referencia.
5. Reconstruyo y publico **Release v0.2.1** con el logo real.
